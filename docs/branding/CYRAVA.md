# CYRAVA — identité de marque (proposition)

> Statut : direction créative retenue, disponibilité juridique non confirmée.

## Positionnement
**CYRAVA** est le nom de l'application de confidentialité numérique (anciennement développée sous le nom de projet RefusBot).

Promesse : aider l'utilisateur à reprendre le contrôle de ses choix de consentement et de sa vie privée numérique, avec des actions prudentes, explicables et vérifiées.

Signature proposée : **CYRAVA — Digital Privacy**.

## Direction artistique
- Univers : cyber premium, futuriste, précis et rassurant.
- Palette : bleu nuit très profond en fond, cyan/turquoise électrique pour les accents, blanc froid pour les textes et reflets.
- Symbole : bouclier géométrique contenant un cadenas. Le bouclier représente la protection ; le cadenas, le contrôle de l'accès et des données.
- Style : lignes nettes, géométrie simple, halo lumineux mesuré, contraste élevé.
- Interface cible : tableau de bord sombre, cartes lisibles, coins arrondis, navigation cohérente, micro-interactions discrètes.

## Principes UX
1. La lisibilité et l'accessibilité priment sur les effets lumineux.
2. Ne jamais afficher un score, une action réussie ou un état de consentement qui n'est pas réellement mesuré.
3. Distinguer clairement détection, action tentée, action acceptée par Android et état final vérifié.
4. Ne jamais désactiver un choix si son état initial est inconnu.
5. Conserver un mode clair accessible si l'application le propose ; la marque cyber ne doit pas nuire au confort.

## Nommage Android
- Nom de marque envisagé : CYRAVA.
- Sous-titre descriptif : Digital Privacy.
- Le nom de l'APK, le nom affiché par Android, l'identifiant d'application et les textes de documentation sont des éléments distincts. Ne pas les renommer tous automatiquement.
- Aucun renommage technique n'est effectué par ce document.

## Icône
Le fichier `assets/cyrava-logo.svg` est une première proposition vectorielle. Il sert de source de travail pour produire les déclinaisons Android (adaptive foreground/background, monochrome et tailles Play Store). Il doit être contrôlé sur les masques d'icônes Android et sur fond clair/sombre avant intégration dans l'application.

## Vérification de disponibilité
Le nom CYRAVA est une proposition créative, pas une disponibilité garantie. Avant publication ou dépôt :
- rechercher les identités identiques et similaires auprès de l'INPI ;
- vérifier les marques de l'Union européenne dans EUIPO / TMview ;
- vérifier les classes pertinentes, notamment logiciels et services numériques ;
- vérifier domaines, boutiques d'applications et usages commerciaux existants ;
- demander une validation juridique si le projet devient commercial.

Liens de vérification :
- https://data.inpi.fr/search
- https://www.tmdn.org/tmview/

## Gouvernance
Le nom CYRAVA, l'icône et l'identifiant `fr.cyrava` sont en place depuis la 1.1.0 bêta 2. Seuls les dossiers du code source s'appellent encore `fr.refusbot`, ce qui ne se voit pas sur le téléphone.
